📸 Smart Attendance System (Face Recognition)

An automated attendance management system that uses facial recognition technology to detect and identify individuals in real-time. The system automatically marks attendance, stores records securely, and eliminates the need for manual entry — ensuring accuracy, efficiency, and authenticity.

⸻

🚀 Features
	•	✅ Real-Time Face Detection & Recognition using OpenCV & face_recognition
	•	✅ Automated Attendance Marking with secure digital record-keeping
	•	✅ Database Integration with MySQL / MongoDB
	•	✅ Reports Generation for monitoring attendance trends
	•	✅ User-Friendly Interface for admins and users
	•	✅ Scalable for classrooms, offices, or organizations

⸻

🛠️ Technology Stack
	•	Programming Language: Python
	•	Libraries/Frameworks: OpenCV, NumPy, face_recognition
	•	Database: MySQL / MongoDB
	•	GUI (Optional): Tkinter / Web Interface

 
⚙️ Installation & Setup

1️⃣ Clone the repository
git clone https://github.com/your-username/smart-attendance-system.git
cd smart-attendance-system

2️⃣ Install dependencies
pip install -r requirements.txt

3️⃣ Set up the database
Configure MySQL/MongoDB connection in config.py.
Create a table/collection for attendance records.

4️⃣ Run the application
python main.py


🎯 Usage
	1.	Register Faces – Add student/staff images to the system.
	2.	Start Application – Ensure the camera is connected.
	3.	Face Recognition – The system detects faces and marks attendance automatically.
	4.	Reports – Generate and export attendance reports as needed.
